# Инструкция по управлению ИИ-помощником

Эта инструкция относится к файлу `ai-puzzle-assistant.snippet.js`. Текущая версия запускается как Snippet в Chrome DevTools и работает только на открытой вкладке, где была запущена.

## 1. Установка скрипта в Chrome

1. Откройте нужную веб-страницу.
2. Нажмите `F12` или `Ctrl+Shift+I`, чтобы открыть Chrome DevTools.
3. Перейдите во вкладку `Sources`.
4. В левой панели откройте раздел `Snippets`. Если он не виден, нажмите `>>` или откройте меню DevTools и выберите `More tools` -> `Sources`.
5. Нажмите `New snippet` и задайте имя, например `AI Puzzle Assistant`.
6. Вставьте содержимое файла `ai-puzzle-assistant.snippet.js`.
7. Перед первым запуском укажите свой ключ DeepSeek в параметре `CONFIG.apiKey` в начале скрипта.
8. Нажмите `Ctrl+S`, чтобы сохранить Snippet.

На macOS вместо `Ctrl` обычно используется `Cmd`.

## 2. Запуск

1. Откройте DevTools на странице, где нужен помощник.
2. Откройте сохраненный Snippet.
3. Нажмите `Ctrl+Enter` (`Cmd+Enter` на macOS) или кнопку запуска в DevTools.
4. На странице появится окно `ИИ-помощник`.

Повторный запуск Snippet автоматически удаляет предыдущий экземпляр помощника на этой странице и создает новый.

После обновления страницы скрипт нужно запустить снова.

## 3. Основная работа

1. Выделите мышью текст задачи на странице.
2. Нажмите кнопку `Решить` или сочетание `Shift+Y`.
3. Дождитесь ответа DeepSeek.
4. Для повторной проверки результата нажмите `Проверить`.

Максимальная длина выделенного текста по умолчанию составляет `10 000` символов.

## 4. Горячие клавиши

| Команда | Клавиши | Результат |
|---|---|---|
| Решить выделенную задачу | `Shift+Y` | Отправляет выделенный текст в DeepSeek |
| Скрыть или показать окно | `Shift+Q` | Переключает видимость помощника |
| Запустить Snippet из DevTools | `Ctrl+Enter` | Запускает или перезапускает помощник |

Горячие клавиши помощника не срабатывают, когда курсор находится в поле ввода, текстовой области, списке или редактируемом элементе страницы.

## 5. Кнопки и элементы окна

| Элемент | Назначение |
|---|---|
| `Решить` | Отправить выделенный текст задачи в DeepSeek |
| `Проверить` | Повторно проверить последний полученный ответ с учетом исходной задачи |
| `Очистить` | Очистить ответ и вернуть помощник в начальное состояние |
| `Отменить` | Прервать выполняющийся запрос; кнопка видна только во время запроса |
| `−` / `+` | Свернуть или развернуть окно |
| `×` | Полностью удалить помощник с текущей страницы |
| `Прозрачность` | Изменить прозрачность окна |

Окно можно перемещать за верхнюю панель. Размер изменяется за правый нижний угол. Позиция, размер, прозрачность и свернутое состояние сохраняются для текущего сайта в `localStorage`.

## 6. Команды в консоли Chrome

Команды выполняются во вкладке `Console` DevTools на той странице, где запущен Snippet.

Показать окно:

```javascript
window.__AI_PUZZLE_ASSISTANT__.show()
```

Скрыть окно:

```javascript
window.__AI_PUZZLE_ASSISTANT__.hide()
```

Переключить видимость:

```javascript
window.__AI_PUZZLE_ASSISTANT__.toggleVisibility()
```

Проверить, установлен ли помощник на странице:

```javascript
window.__AI_PUZZLE_ASSISTANT__.isMounted()
```

Результат `true` означает, что помощник установлен. Результат `false` означает, что его окно отсутствует.

Полностью остановить скрипт и удалить помощник со страницы:

```javascript
window.__AI_PUZZLE_ASSISTANT__.destroy()
```

После `destroy()` для повторного запуска нужно снова выполнить Snippet через `Ctrl+Enter`.

## 7. Изменение настроек

Основные параметры находятся в объекте `CONFIG` в начале файла:

| Параметр | Назначение |
|---|---|
| `apiKey` | Личный API-ключ DeepSeek |
| `apiUrl` | Адрес API DeepSeek |
| `model` | Используемая модель |
| `hotkey` | Сочетание клавиш для решения задачи |
| `toggleHotkey` | Сочетание клавиш для скрытия и показа окна |
| `maxSelectedTextLength` | Максимальная длина выделенного текста |
| `maxTokens` | Максимальный размер ответа модели |
| `temperature` | Степень вариативности ответа |
| `timeoutMs` | Время ожидания ответа в миллисекундах |
| `ignoreHotkeyInEditable` | Отключение горячих клавиш внутри полей ввода |
| `debug` | Дополнительные сообщения в консоли для диагностики |

Пример смены горячей клавиши решения на `Ctrl+Shift+Y`:

```javascript
hotkey: {
  ctrl: true,
  shift: true,
  alt: false,
  key: 'Y',
},
```

После изменения параметров сохраните Snippet и запустите его повторно.

## 8. Сброс сохраненного положения окна

Выполните в консоли на нужном сайте:

```javascript
localStorage.removeItem('aiPuzzleAssistantSettingsV1')
```

Затем перезапустите Snippet. Настройки сохраняются отдельно для каждого сайта, потому что используется хранилище текущей страницы.

## 9. Безопасность

- Не публикуйте Snippet с API-ключом внутри.
- Не отправляйте файл с ключом другим людям.
- В DeepSeek передается выделенный текст задачи. Не выделяйте пароли, платежные данные, личную переписку и другие конфиденциальные сведения.
- Ключ в текущей версии хранится в открытом виде внутри Snippet. Это допустимо только для личного прототипа, но не для публикации расширения в Chrome Web Store.
- Перед созданием публичного расширения ключ нужно убрать из исходного кода. Пользователь должен вводить собственный ключ через защищенные настройки расширения.
- Если ключ когда-либо был опубликован, передан другому человеку или попал в репозиторий, отзовите его в кабинете DeepSeek и создайте новый.

## 10. Частые ошибки

`Добавьте API-ключ DeepSeek` — ключ не указан в `CONFIG.apiKey`.

`HTTP 401` — ключ отсутствует, введен неверно или был отозван.

`HTTP 402` — на аккаунте API недостаточно средств или превышен доступный лимит.

`HTTP 429` — превышена частота запросов; подождите и повторите попытку.

`Браузер заблокировал прямой запрос` — сайт или браузер заблокировал прямое обращение к DeepSeek API. Для полноценного расширения запросы будут выполняться через фоновый процесс расширения.

Окно не появляется — проверьте консоль на наличие ошибок, затем повторно запустите Snippet через `Ctrl+Enter`.

Горячая клавиша не работает — уберите курсор из поля ввода и проверьте, не занято ли сочетание клавиш сайтом или браузером.
